# General Knowledge Brief

Interactive briefings for Knowledge Sharing sessions, hosted on GitHub Pages:
**https://reverii.github.io/General-Knowledge-Brief/**

| Brief | Link | Length |
|---|---|---|
| The Invisible Battlefield: Electronic Attack (EA) Explained | [electronic-attack/](https://reverii.github.io/General-Knowledge-Brief/electronic-attack/) | 12 slides, ~15 min |

## Presenting

- Open in Chrome or Edge (needs internet — Three.js loads from a CDN).
- `→` / `Space` next, `←` back, `N` speaker notes, `T` start/pause timer, `F` fullscreen.
- Drag to orbit the 3D scene, scroll to zoom.

Each brief is a single self-contained `index.html` in its own folder.
